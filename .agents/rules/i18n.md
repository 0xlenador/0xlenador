# i18n — Sistema de Internacionalización

## Arquitectura
- **Español** = idioma default, SIN prefijo de URL (`/blog/`, `/activos/`)
- **Inglés** = bajo `/en/` (`/en/blog/`, `/en/watchlist/`)
- Config: `prefixDefaultLocale: false` en `astro.config.mjs`

## Traducciones de UI

Los textos viven en micro-diccionarios JSON separados por namespace:
`src/i18n/locales/{es,en}/{namespace}.json`

Se acceden con la función tipada `t("clave")`:
```ts
import { getLangFromUrl, useTranslations } from "../i18n"
const lang = getLangFromUrl(Astro.url)
const t = useTranslations(lang)
// t("nav.herramientas") → "Herramientas" (es) / "Tools" (en)
```

Para datos JSON bilingües (`{ es: "...", en: "..." }`), usar `getBilingual(field, lang)` de `src/i18n/utils.ts`.

## Reglas Obligatorias

1. **Siempre crear ambas versiones (ES + EN).** Al crear o modificar una página, componente o contenido, asegurar que exista la versión en inglés (`src/pages/en/`). No dejar la versión EN pendiente ni omitirla.

2. **Traducir TODO al inglés.** Al crear llaves en los JSON de `en/`, traducir completamente al inglés. Cero palabras en español en los archivos de `en/`. Revisar cada valor antes de terminar.

3. **Cero llaves huérfanas.** Al renombrar, mover o eliminar una llave de traducción, actualizar **ambos** archivos (`es/{namespace}.json` y `en/{namespace}.json`). No dejar llaves que ya no se usan.

## Checklist: Nueva página estática con slug diferente entre idiomas

1. Crear `.astro` en `src/pages/` (ES) y `src/pages/en/` (EN)
2. Agregar segmento en `src/i18n/ui.ts` → objeto `routes` (ambas direcciones)
3. Agregar ruta en `src/i18n/utils.ts` → objeto `routeMap`

> Si el slug es **igual** en ambos idiomas (ej: `/riskfolio`), no tocar nada de i18n.

## Contenido dinámico (blog, guías)

Los slugs traducidos se manejan con `translationSlug` en el frontmatter del Markdown/MDX.
El sitemap y hreflang se resuelven automáticamente via `sitemapHelpers.mjs`.

## Agregar nuevo namespace de traducciones

1. Crear `src/i18n/locales/es/{namespace}.json` y `en/{namespace}.json`
2. Agregar el `import type` en `src/i18n/ui.ts`
3. Agregar al type `AllTranslations` en el mismo archivo

## Anti-patrones (NUNCA hacer)

- **NUNCA duplicar archivos .astro** para traducir. Usar el sistema i18n existente.
- **NUNCA hardcodear textos** en componentes. Todo texto visible va en los JSON de locales.
- **NUNCA modificar `buildDictionary()`** ni el sistema de carga. Si necesitas una excepción, consultar primero.
